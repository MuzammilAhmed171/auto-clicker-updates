# Auto Clicker Pro - Updates

Ye public repo sirf update maloomat ke liye hai. Koi token ya login nahi chahiye.

## Update kaise kaam karta hai (v1.2.0 se)
1. App is repo ki `version.json` file dekhta hai - naya version hai ya nahi.
2. Naya version ho to app portable zip Google Drive se download karta hai (driveId aur size version.json me hote hain, size check bhi hoti hai).
3. App khud band ho kar naya version laga kar dobara khul jata hai. Settings AppData me rehti hain, safe rehti hain.

Latest version: **1.2.0** - `version.json` dekho.
